🔎 Harmonies Sound Check

Every test here measures its own output with an analyser, so it can tell "the code produced no sound" apart from "the code produced sound you couldn't hear" — the previous version could not, which is why it was misleading. Run the steps in order.

⏳ Running offline self-test…

Step 0 — Offline self-test (automatic; no speaker involved)

Renders the audio graph into a buffer and measures the actual samples. Needs no tap and no working speaker. If this passes, the code demonstrably produces sound.

Step 1 — Plain <audio> element ★ do this FIRST

Not WebAudio at all — an entirely separate pipeline. If this is silent too, the fault is the device rather than WebAudio.

Step 2 — Sustained WebAudio tone (10s)

Long enough to adjust volume, flip the silent switch or disconnect Bluetooth while it plays. On iOS the volume buttons only change media volume while audio is playing.

Step 3 — The game's own sound engine

A mountain token, the card-complete chime and a water droplet — the real engine, measured.
