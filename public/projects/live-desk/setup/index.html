Live desk

A rules file for your coding agent: Claude Code, Codex, Amp or another, in any editor or terminal.

Built and used with Claude Code; Codex, Amp and others should follow it but are untested.

The agent writes each session's replies to a markdown file, the session's desk. You read it in Obsidian and answer next to the line you mean.

After ten turns it's hard to say what's done, what's happening now and what's next, because the answers are buried in chat. The desk keeps all of it in one file that stays where you left it.

Try it in 5 minutes

  1. Paste it into your agent. It installs the rules and tells you what it changed.

  2. In Obsidian, open ~/claude-replies as a vault.

  3. Start a new session and send:Start a live desk for this session: <what you're working on>

    It worked when a new desk opens as a tab in Obsidian.

How a turn goes

In the Director deck's words: you're the Director, each session is a manager, and the desk is the board at its gate.

  1. You
    >> yes

    Answer in the file

    Read the desk in Obsidian and type your answer next to the line you mean.

  2. You
    >>

    Send >> in chat

    That can be the whole message. Send it too when a step you were doing is done.

  3. Agent
    ✓§5

    The agent reads and works

    One grep finds your open answers. It does the work, updates Status, adds a Log entry and marks each answer it handled.

  4. Agent
    entry 5

    One line back

    In chat you get the gist and a link to the new entry.

your move again

Any message works too. The agent checks the desk for open answers at the start of every turn.

What a desk looks like

One desk per session: Status on top, the Log below.

1Status: rewritten each turn, so it's always current.

  1. 2

    Now: whose move it is, yours or the agent's.

  2. 3

    Your answer: >> and your reply, on the question's line.

  3. 4

    Next: Yours and Mine steps; tick yours when done.

  4. 5

    Decisions and Done: one line each, with its log entry.

6Log: one entry per reply, never rewritten.

  1. 7

    Handled: ✓§5 names the entry that handled it.

  2. 8

    Highlighted: what you need to do, written ==…==. Status lists it once, as an open question or a Yours step, and Now points to it.

Set it up by hand Claude Code on macOS, one copy at a time
  • Another agent: copy live-desk.md into its global instructions file, such as ~/.codex/AGENTS.md for Codex, and make the desk folder.
  • For each file below, paste the command into Terminal first, then copy the file, then press Return. In the other order, the command would save itself.

  1. Save the rules

    1. Copy the command, paste it into Terminal, don't press Return yet.

      Terminal
      mkdir -p ~/.claude/rules && pbpaste > ~/.claude/rules/live-desk.md

    2. Copy live-desk.md.

    3. Press Return in Terminal.

  2. Make the desk folder

    Terminal
    mkdir -p ~/claude-replies

  3. Add the allow rules

    Into permissions.allow in ~/.claude/settings.json.

    ~/.claude/settings.json
    "Edit(~/claude-replies/**)",
"Bash(open \"obsidian://open?*)",
"Bash(date:*)"

  4. The hook Optional

    1. Copy the command, paste it into Terminal, don't press Return yet.

      Terminal
      mkdir -p ~/.claude/hooks && pbpaste > ~/.claude/hooks/desk-nudge.sh && chmod +x ~/.claude/hooks/desk-nudge.sh

    2. Copy desk-nudge.sh, then press Return in Terminal.

    3. Merge this into the "hooks" object in ~/.claude/settings.json.

      ~/.claude/settings.json
      "PostToolUse": [
  {"hooks": [{"type": "command", "command": "~/.claude/hooks/desk-nudge.sh", "timeout": 5}]}
],
"UserPromptSubmit": [
  {"hooks": [{"type": "command", "command": "~/.claude/hooks/desk-nudge.sh", "timeout": 5}]}
],
"PreToolUse": [
  {"matcher": "Edit|Write|MultiEdit", "hooks": [{"type": "command", "command": "~/.claude/hooks/desk-nudge.sh", "timeout": 5}]}
]

  5. The desk script Optional

    1. Copy the command, paste it into Terminal, don't press Return yet.

      Terminal
      mkdir -p ~/.claude/bin && pbpaste > ~/.claude/bin/desk && chmod +x ~/.claude/bin/desk

    2. Copy desk, then press Return in Terminal.

    3. Add its allow rule to permissions.allow in ~/.claude/settings.json.

      ~/.claude/settings.json
      "Bash(~/.claude/bin/desk:*)"

  6. Focus view Optional

    Into your VS Code user settings.

    VS Code settings.json
    "claudeCode.focusView": true,
"claudeCode.scrollToBottomOnSend": false

Add todos

Add a todo any time, in chat or in the file. It stays on the board under Next until it's done, even across a handoff.

Handoff

The whistle: hand off long sessions

When a session gets long, the agent asks whether to continue in a fresh one. Say yes and it writes a Handoff entry that opens with a line to paste into the new session: Resume from the live desk ~/claude-replies/<file>, handoff §<n>.

Limits

  • The rules name Claude Code's tools and macOS's open, so another agent or OS may need small wording edits.
  • The link to the new entry in the chat line opens in VS Code; in a terminal it's plain text.
  • The hook enforces one rule, keeping keys and email addresses out of a desk, and it can't spot query rows or names. Nothing enforces the rest. It's still a trial.
  • In VS Code, tool approvals still pull the panel to the bottom.
  • The manual steps use pbpaste, which is macOS only.

Questions

Doesn't it burn tokens?

Each turn costs one grep and the Status block, plus a re-read of the file after you edit it in Obsidian.

Does Status stay current?

In the trial it was current at the end of every turn. It went quiet inside long turns, which the hook now nudges.

Can I read it on my phone?

Put ~/claude-replies in a synced Obsidian vault, after checking that work notes may sit in that cloud.

What stays out of a desk?

Keys, passwords, query rows and customer details. A scan of 13 work desks (about 8,200 lines) found no keys, passwords or customer emails.

Do I need Obsidian?

No. Any markdown editor that saves on its own works. Change the rules' open command and the allow rules to match.

How do I stop?

Remove what you installed:
  • the rules file, ~/.claude/rules/live-desk.md, or the rules in your agent's instructions file
  • the allow rules in ~/.claude/settings.json
  • the hook, ~/.claude/hooks/desk-nudge.sh, and its "hooks" entries
  • the script, ~/.claude/bin/desk, and its allow rule
